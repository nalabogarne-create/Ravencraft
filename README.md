# Ravencraft 🏰

A mobile 3D gothic castle game project.

## Deployment status

The game is being prepared for web hosting. This repository is initialized, but the full game assets have **not yet been uploaded** and GitHub Pages is **not yet enabled**.

## Planned structure

- `index.html` — mobile 3D game
- `assets/aurel.glb` — character model
- `assets/stone_albedo.jpg`, `assets/stone_height.jpg` — stone materials
- `assets/wood_albedo.jpg`, `assets/wood_height.jpg` — wood materials

The project owner should avoid making the repository public until comfortable publishing its contents.
